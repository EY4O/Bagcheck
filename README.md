<h1 align="center">Bagcheck</h1>

<p align="center"><strong>A shopping list and retainer tracker for crafters.</strong></p>

Know what you need, what you have, and where it's cheapest. Bagcheck keeps count; you do the shopping.

## Features

- **Shopping List:** add items by search, from the right-click menu, or by pasting a Teamcraft list.
- **Need and have:** counts what you hold across your bags, crystals, saddlebag and retainers.
- **Prices:** the cheapest worlds on your data centre, NPC vendors that sell for less, and what finishing the list
  would cost, from [Universalis](https://universalis.app).
- **Retainers:** each retainer's gil and listings, and which listings have been undercut.

## Installation

1. In game, open `/xlsettings`.
2. Under **Experimental > Custom Plugin Repositories**, add this URL and save:

   ```text
   https://ey4o.github.io/XIV-Plugins/repo.json
   ```

3. Open `/xlplugins`, then find and install **Bagcheck**.

## Commands

| Command | What it does |
| --- | --- |
| `/bagcheck` | Open Bagcheck |
| `/bagcheck settings` | Open the settings |
| `/bagcheck welcome` | Open the welcome guide |
